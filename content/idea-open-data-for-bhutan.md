What if finding public data about Bhutan were as easy as browsing a catalogue?

## The idea

A community-maintained index of open datasets, starting small:

- bus routes and timetables between dzongkhags
- tourism arrival statistics
- air-quality and weather observations

Each dataset entry would itself be a markdown file — exactly like this post — so anyone can propose a new dataset via pull request.

## Why it matters

Open, machine-readable data lowers the barrier for students, journalists, and developers to build things that benefit everyone. The hardest part is rarely the technology; it is knowing the data exists.

If you know of a dataset worth listing, open a pull request and share it.
